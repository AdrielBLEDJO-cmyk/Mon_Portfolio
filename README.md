# Mon Portfolio

Bienvenue sur mon portfolio personnel. Ce projet présente mon profil, mes compétences, mes réalisations et mes projets web.

## Présentation

Ce portfolio a été conçu pour présenter :

- mon profil professionnel ;
- mes compétences;
- mes projets réalisés ;
- mes informations de contact.

Il s'agit d'un site web statique, simple et moderne, pensé pour être facilement consultable et navigable.

## Structure du projet

```text
Mon Portfolio/
├── index.html
├── profil.html
├── competences.html
├── projets.html
├── contact.html
├── styles.css
├── photo-profil/
├── projets/
│   ├── demo-meubles/
│   └── demo-resto/
└── README.md
```

## Pages principales

- `index.html` : page d'accueil du portfolio
- `profil.html` : présentation personnelle
- `competences.html` : compétences et outils
- `projets.html` : liste des projets
- `contact.html` : formulaire ou moyens de contact

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (pour certaines démos de projets)

## Comment consulter le site

1. Ouvrir le fichier `index.html` dans un navigateur.
2. Ou bien utiliser un serveur local simple si tu veux tester le site de manière plus proche d'un environnement web.

Exemple avec Python :

```bash
python -m http.server 8000
```

Ensuite, ouvre l'URL suivante dans ton navigateur :

```text
http://localhost:8000
```

## Projets inclus

Le dossier `projets/` contient des démonstrations web, notamment :

- `demo-meubles` : projet de boutique / catalogue de meubles
- `demo-resto` : projet de restaurant / carte et réservation

## Objectif

Ce portfolio sert à mettre en valeur mes compétences en développement web et à présenter les projets que j'ai réalisés de manière claire et professionnelle.
